EmbeddedInfrastructure

An infrastructure library for ESP32/Arduino applications that provides
reusable subsystems for networking, logging, storage, time, MQTT, events,
and system lifecycle management.

Status

🚧 Active development

This project is undergoing a compiler-driven architectural migration toward
a subsystem-oriented design.

Current goals

• Deterministic startup lifecycle
• Strong subsystem ownership
• Structured logging
• Persistent configuration
• Event-driven architecture
• Reusable infrastructure independent of applications

See the docs directory for architecture, subsystem design, and migration notes.
